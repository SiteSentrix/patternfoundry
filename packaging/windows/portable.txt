PatternFoundry portable mode

While this file sits next to patternfoundry.exe, PatternFoundry keeps its preferences, swatch and
graphic style libraries, added fonts, crash-recovery files and logs in the PatternFoundryData folder
beside it, and writes nothing to %APPDATA%. Copy the whole folder to move PatternFoundry with its
settings. The first time PatternFoundryData is created, any settings already in
%APPDATA%\PatternFoundry are copied into it; the originals are left where they were.

Keep this folder somewhere only you can write to: whoever can write here decides your settings,
including the plug-ins and fonts folders PatternFoundry loads from, and the Data Recovery copies of
your unsaved documents are kept here too.

Delete this file to use the normal per-user settings folder (%APPDATA%\PatternFoundry) instead.
If PatternFoundryData can't be written (for example on a read-only drive), PatternFoundry logs a
warning and uses %APPDATA%\PatternFoundry instead.
