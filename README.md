# PatternFoundry

Sewing-pattern design software: draft from measurements, change the design, grade sizes, and
print or export at true scale. By [SiteSentrix](https://sitesentrix.com), the makers of
[StitchFoundry](https://stitchfoundry.app). Based on VectorCraft by the ArtCraft team.
